# Chess World — installers and updates

This repository only hosts **Chess World** installers and the in-app update feed (`latest.json`).
The game's source code is proprietary and is not published here.

Download the latest version from [Releases](https://github.com/ralabarta/chess-world-releases/releases).

## Third-party components

Chess World ships the **Stockfish** chess engine as a separate program. Stockfish is free software
under the GNU General Public License v3; its complete source code is available at
<https://github.com/official-stockfish/Stockfish> (the exact version bundled is listed in each release's notes).

Human-like move prediction uses the **Maia-3** network weights by CSSLab (University of Toronto),
included with permission and credited in the app (Settings → Credits).
